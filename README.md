# 8051 I2C  Communication

This project demonstrates basic I2C communication using software-driven signals on the 8051 microcontroller.

## Features

- Start/stop protocol generation (I2C)
- Byte transmission
- Bit-level communication
- GPIO-based implementation

## Tools Used

- Embedded C
- Keil uVision
- 8051 microcontroller
- Proteus simulation

## Learning Goals

- Serial communication fundamentals
- Timing control
- Embedded driver structure
